# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records for the CentRAG platform.
An ADR is a short text file in a format similar to an Alexandrian Pattern that describes a set of forces and a single decision in response to those forces.

## Process
Whenever a Principal Architect or autonomous agent makes a significant structural change (e.g., changing database technologies, altering the composition root, defining a new chunking protocol), a new ADR must be appended here.

## Benefits
- Prevents repeating past mistakes or reversing sound architectural decisions.
- Onboards new engineers and agents quickly by explaining *why* things are built the way they are.
- Exposes SDLC decision-making to the continuous review cycle of the `code-review-graph`.
